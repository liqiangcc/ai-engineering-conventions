# 身份检查迁移

## 变化

UC001/BR001 保留逻辑身份唯一的语义，明确区分定义与引用，不再允许通过 ID 出现次数判断唯一性。无法区分时报告 NOT_VERIFIED；Checker 补充退出码 4，与统一验证入口对齐。

## 采用步骤

1. 按[身份定义与引用](../traceability/identity-system.md#身份定义与引用)确认项目已有权威元数据；不能增加第二份人工映射表。
2. 对合法多处引用、同一 BR 多实现、重复主要 UC、重复 BR 定义、冲突声明及来源不足建立 Checker fixture。
3. 来源不足不能录为 PASS，也不能误报重复 ID；必需检查通过统一入口返回非零码 4。
4. 普通命名规则迁至 Convention Checker，先确认其检查已生效再移除重复 Architecture 检查；不得丢失现有边界保护。

历史 Pilot 本地规则与运行证据不因本次规范澄清而改变。

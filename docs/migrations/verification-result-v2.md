# Verification Result v2 迁移

## 接口变化

结果示例版本由 1 更新为 2，保留结果字段和状态/结论枚举。补全必需范围、非必需失败、环境错误、已有失败与空集合的汇总规则；空 results 不再示例为 VERIFIED。当前语义见[结果规范](../schemas/verification-result.md)。

命令新增退出码 4 表示必需验证不完整；非必需失败不再触发退出码 1。组合错误按[命令规范](../automation/verification-command.md#exit-code)确定优先级。

## 采用步骤

1. 消费者先支持 version=2 和退出码 4；未知版本应明确不支持，不自动当作通过。
2. 生产者在执行前确定必需集合，保留未执行项；按 v2 决策表汇总后输出 version=2。
3. CI 必须阻断退出码 1/2/3/4，退出码 0 时仍展示非必需问题。
4. 模板的 N/A 仅用于不适用；已有未执行的 N/A 需重新分类，不能批量映射成 NOT_REQUIRED。
5. 使用规范中的验收场景验证生产者与消费者，然后启用新版门禁。

历史 v1 报告保留原版本和当时证据；需要按 v2 判断时必须用原始结果重新计算，不能只修改版本号。历史 Pilot 状态不因规范升级而变成已验证。
